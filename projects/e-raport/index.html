E-Raport Application

A digital report-card application for junior high schools and PKBM with many local-content subjects.

1 / 10

This application is built with the laravel 7.0 framework and MySQL DBMS using a template from the LTE admin. Suitable for use in equivalent junior high school education institutions or PKBM which have many local content subjects so they cannot use the E report application from the Education Office.

Key Features

  • Multi users (Admin, Teacher, Homeroom, Student).
  • Responsive Display.
  • Supports 2 Types of Curriculum, namely Curriculum KTSP 2006 & K13.
  • Supported with Import Excel for data and value input menu.
  • Master & Leger Student Value data can be downloaded into Excel format.
  • Report files and student IDs can be downloaded in PDF format.
