TreePort API

A RESTful API for tree, species, location, and user data, with forestry analytics reports.

1 / 3

This API provides services for managing tree data, species, locations, users, and supports authentication as well as analytical reports related to forestry.

The API supports HTTP methods (GET, POST, PUT, DELETE) with detailed documentation on parameters and response structures.

Key Features

  • Tree Management: Add, update, delete, and retrieve tree data.
  • Species Management: Manage tree species data.
  • Location Management: Manage forest and planting area data.
  • User Management: User registration, authentication, and management.
  • Reports & Analytics: Tree growth data and forest health analysis.
  • Notifications: Send important alerts to users.
