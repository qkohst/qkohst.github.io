Manajemen Karyawan

Sistem pengelolaan data karyawan, gaji, divisi, dan departemen berbasis Laravel.

1 / 3

Sistem ini dibangun dengan framework Laravel dan basis data MySQL menggunakan Bootstrap CSS.

Fitur Utama

  • Masuk dan keluar, lupa kata sandi (akun terkunci 5 menit setelah 3 kali percobaan gagal).
  • Kelola karyawan (tambah, ubah, dan hapus).
  • Kelola negara, kota, dan provinsi (tambah, ubah, dan hapus).
  • Kelola pengguna (tambah, ubah, dan hapus).
  • Kelola gaji (tambah, ubah, dan hapus).
  • Kelola divisi (tambah, ubah, dan hapus).
  • Kelola departemen (tambah, ubah, dan hapus).
  • Menyusun laporan (ekspor ke Excel dan PDF).
  • Pencarian (dengan kombinasi beberapa kolom).
  • Penomoran halaman
  • Validasi
  • Responsif
