St Pamdes

A customer data and water payment application for village water management.

1 / 10

This application is built with the laravel 7.0 framework and MySQL DBMS. Pamdes is a solution to assist in customer data collection and water payment transactions.

Key Features

  • Customer Data Collection
  • Water Usage Recording
  • Payment Transaction Recording
  • Print Proof of Payment
  • Transaction Reports
  • Check bill
  • Import & Export Excel
  • Export PDF
  • Payment Proof Paper Size Settings
