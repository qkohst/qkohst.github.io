Summary

  1. 01

    A school administration platform that consolidates work normally scattered across spreadsheets and paper ledgers.

  2. 02

    Six user roles with separated permissions, so each staff member sees only the data they are responsible for.

  3. 03

    Developed incrementally since 2021 and still being extended — a mature system, not a prototype.

  4. 04

    Two routes available: buy a ready-to-use licence, or have it built to your school's own rules.

The problem it solves

  • Student records, grades, and payments live in separate spreadsheets that are easily overwritten.
  • Attendance is tallied by hand at every month's end — slow, and easy to get wrong.
  • Student billing and payments are hard to trace when a parent asks about them.
  • Incoming and outgoing mail is never logged, so nothing can be found when it is needed.
  • Discipline records sit in each teacher's own notebook and never accumulate into a picture.
  • Parents only learn about a problem at report time, far too late to act on it.

Proposal · School Management Information System 04

The proposed solution

All administrative work moves into one place with firm separation of access. A teacher records attendance for their own class, finance staff never touch academic records, and a student sees only their own file.

Everything that matters to a parent — attendance, discipline, and payment receipts — is sent automatically over WhatsApp the same day, so the school does not have to wait for the end of term to communicate.

Every report exports to both Excel and PDF, so the formats the school already uses for district reporting can still be produced without retyping anything.

Who uses it

  • AdminSchool master data, academic year, teachers, study groups, and students.
  • Correspondence AdminClassification, incoming and outgoing mail, disposition, and mail agenda.
  • Finance AdminStudent billing, payment transactions, savings, and school cash flow.
  • TeacherDaily attendance for the subjects they teach, and their teaching timetable.
  • Counselling TeacherRecording violation points and handling student welfare cases.
  • StudentViewing their own attendance, bills, savings, and discipline record.

Questions and answers

What if the developer stops working or cannot be reached?
The application keeps running because it is installed on your own server, not on a service I operate. A copy of the database and instructions for backing it up are handed over at handover, so another developer can take over if needed.
Why is the source code not included?
That is precisely why the licence costs far less than building from scratch. If you do need the source code, there is the bespoke route, or buying the source code under a separate agreement.
Can our existing data be moved in?
Yes, as long as it is in Excel or can be exported to Excel. Loading the initial data is included in the licence price.
Is there a limit on the number of users?
No. The licence covers one institution with no cap on accounts or on the number of computers using it.
What if we need a menu or report that does not exist yet?
It can be added as additional work. The estimated hours and cost are stated and agreed first — never built quietly and invoiced afterwards.
Do we need an internet connection?
Not necessarily. Installed on a local server, the application runs over the network inside the building. Internet is only needed if you want to open it from outside.
Can we try it before buying?
Yes. I will show you the application running with sample data, over an online meeting or a visit, before you decide.
