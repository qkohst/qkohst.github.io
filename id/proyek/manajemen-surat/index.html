Sistem Manajemen Surat

Pengelolaan surat masuk dan keluar beserta klasifikasi, unggahan berkas, dan cetak agenda.

1 / 3

Sistem ini dibangun dengan framework Laravel dan basis data MySQL menggunakan templat AdminLTE.

Fitur Utama

  • Multi pengguna (Admin, Petugas).
  • Mengelola data surat masuk dan surat keluar.
  • Mengunggah berkas surat masuk dan surat keluar.
  • Mengelola klasifikasi surat.
  • Mencetak agenda surat masuk dan surat keluar.
  • Melihat galeri berkas surat masuk dan surat keluar.
