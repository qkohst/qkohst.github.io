The problem it solves

  • The government-issued report tool has no room for local-content subjects, so those marks are still worked out by hand outside the system.
  • Marks arrive as spreadsheets in a different shape from every teacher, then have to be merged again by one person.
  • Homeroom teachers retype an achievement description for every student, even though they all derive from the same competencies.
  • As report day approaches, there is no quick way to see whose marks are still missing.
  • Predicates and pass thresholds are worked out by hand, so a small discrepancy is hard to trace when a correction comes in.
  • Report cards and student ID cards are rebuilt from scratch every term, from files that already existed last year.

The proposed solution

The school registers its own subjects, local content included, each with its pass threshold and predicate bands. The system takes that list as given, so no subject is left to be calculated outside the application.

Teachers enter marks directly against the basic competencies they teach, and each student's achievement description is assembled from those same competencies. The homeroom teacher reviews rather than retypes.

The admin sees a completeness board showing each teacher's planning and assessment status per subject, so anything lagging surfaces well before report day.

Who uses it

  • AdminMaster data, teaching assignments, pass thresholds, predicate bands, and grading progress monitoring.
  • Subject TeacherAssessment plans and entry of knowledge, skill, attitude, and extracurricular marks.
  • Homeroom TeacherAttendance, notes, review of their class's marks, and printing report cards.
  • StudentViewing their own marks and report results.
